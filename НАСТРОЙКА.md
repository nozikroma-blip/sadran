# Настройка совместной работы

Приложение хранит проекты и задачи в облачной базе Supabase, поэтому назначенная
задача сразу появляется у исполнителя на его компьютере. Настройка делается
один раз, дальше участники только вводят почту и пароль.

## Шаг 1. Создать проект Supabase (5 минут, делает владелец)

1. Откройте <https://supabase.com> и зарегистрируйтесь (можно через Google или GitHub).
2. Нажмите **New project**.
   - **Name** — например `projects`.
   - **Database Password** — придумайте и сохраните. Он нужен только для прямого
     доступа к базе, в приложение его вводить не надо.
   - **Region** — выберите ближайший к вам регион, так будет быстрее.
3. Дождитесь, пока проект развернётся (1–2 минуты).

Бесплатного тарифа хватает с большим запасом: он рассчитан на 500 МБ базы и
50 000 активных пользователей в месяц. Единственное ограничение — проект
«засыпает» после недели полного бездействия и просыпается при первом входе.

## Шаг 2. Создать таблицы

1. В Supabase слева выберите **SQL Editor** → **New query**.
2. Откройте файл `supabase-schema.sql` из этой папки, скопируйте всё содержимое
   и вставьте в редактор.
3. Нажмите **Run**. Должно появиться `Success. No rows returned`.

Скрипт создаёт таблицы `profiles`, `projects`, `tasks`, настраивает права
доступа и включает мгновенные обновления. Его можно запускать повторно — ничего
не сломается.

## Шаг 3. Отключить подтверждение почты (по желанию)

По умолчанию Supabase просит каждого нового пользователя подтвердить почту
письмом. Для небольшой команды это лишний шаг:

**Authentication** → **Sign In / Providers** → **Email** → выключить
**Confirm email** → **Save**.

Если оставить включённым — всё работает, просто после регистрации нужно перейти
по ссылке из письма и затем войти.

## Шаг 4. Взять адрес и ключ

**Project Settings** → **API**. Понадобятся два значения:

- **Project URL** — вида `https://xxxxxxxx.supabase.co`
- **anon public** — длинная строка, начинается с `eyJ...`

Ключ `anon public` не секретный, он и предназначен для клиентских приложений:
доступ к данным закрыт правилами на стороне базы, без входа по паролю через него
ничего не прочитать. Ключ `service_role` не используйте и никому не давайте.

## Шаг 5. Раздать приложение команде

1. Отправьте каждому участнику установщик `Проекты Setup 1.1.0.exe`.
2. Отправьте им же **Project URL** и **anon public** — их вводят на первом экране
   («Подключение к команде»), одинаковые у всех.
3. Каждый нажимает «Нет аккаунта? Зарегистрироваться», вводит имя, почту и пароль.

После регистрации человек появляется в списке исполнителей у всех остальных, и
на него можно назначать задачи.

## Как это работает в жизни

- Назначили задачу — у исполнителя она появляется в разделе **«Мои задачи»**
  в течение секунды, приложение перезапускать не нужно.
- В «Моих задачах» задачи разложены по срочности: просроченные, сегодня,
  ближайшая неделя, позже, без срока.
- В боковой панели у «Моих задач» красный счётчик невыполненных.
- Исполнителя и статус можно менять прямо в строке таблицы.
- Внизу слева индикатор: зелёная точка и «Синхронизация включена» означают,
  что связь с базой есть.

## Важно знать

- **Все участники видят все проекты.** Это модель «одна команда — общее
  пространство». Разделение по правам можно добавить позже.
- **Нужен интернет.** Офлайн-режима сейчас нет: без связи приложение покажет
  «Нет связи с базой».
- **Удаление проекта удаляет его у всех** вместе со всеми задачами.
- **Бэкап.** Supabase делает свои резервные копии, но выгрузить данные самому
  можно в любой момент: Table Editor → таблица → Export → CSV.

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| «В базе нет нужных таблиц» | Не выполнен Шаг 2 — запустите `supabase-schema.sql` |
| «Неверная почта или пароль» | Проверьте раскладку; пароль можно сбросить в Supabase → Authentication → Users |
| «Почта не подтверждена» | Откройте письмо от Supabase или выключите Confirm email (Шаг 3) |
| «Нет связи с базой» | Проверьте интернет; убедитесь, что проект Supabase не на паузе |
| Ввели не тот адрес базы | Внизу экрана входа — «Подключиться к другой базе» |
